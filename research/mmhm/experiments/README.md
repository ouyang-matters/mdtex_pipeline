# experiments/ — sweep, verification, aggregation

Everything the paper reports is regenerated by the commands below; nothing is
typed by hand. `PLAN.md` says what each experiment asks and how the sweep
deviates from the original plan; `ENVIRONMENT.md` describes the machine and
the scheduling.

## What was run, and with which engine

* Engine: `results/ENGINE.txt`. Every run used the Release binary built from
  the `engine/` sources of commit `a584eec` (git tree recorded there; the
  sources have not changed since).
* Workloads: `results/WORKLOADS_MANIFEST.csv` has one row per instance: the
  exact generator command, seed, generator version, the `.seq` SHA-256 (checked
  against the file) and size. `workloads/data/` is git-ignored (~1.4 GB); the
  generators are deterministic, so the commands recreate it byte for byte.
* Runs: `configs/E*.json` (written by `configs/make_configs.py`), one
  `results/<exp>/manifest.csv` row per run (command, exit status, wall time).
  `results/NOT_RUN.csv` lists configured runs without results (none).

## Regenerate everything

From `research/mmhm/`:

```sh
# 0. engine (Release) and its tests
cmake -S engine -B engine/build-release -DCMAKE_BUILD_TYPE=Release
cmake --build engine/build-release -j4 && (cd engine/build-release && ctest -j4)

cd experiments
# 1. workloads (all instances, seeds 0-2) -> ../workloads/data/
python3 run.py configs/E*.json --only-gen
python3 workloads_manifest.py          # hashes must match: exits 3 otherwise

# 2. the sweep (resumable; <= 2 timed runs at once; 30-min per-run limit)
python3 run.py configs/E1.json configs/E2.json configs/E3.json configs/E4.json \
    configs/E5.json configs/E6.json configs/E7.json configs/E0.json configs/E0rc.json \
    --mixed --timed-slots 2 --untimed-slots 2 --timeout 1800

# 3. timing noise / interference, sample cross-check
python3 noise.py                       # W2 N=22: 5 runs alone, 3+3 under load
python3 noise.py --extra               # 3 more instances x 3 methods, 5 runs alone;
                                       # alone vs loaded at ~1e6 simplices
python3 crosscheck_samples.py          # all exact configs + Python reference on samples

# 4. correctness gate, then numbers, tables, figures
python3 verify.py                      # exits 3 on any mismatch, 4 if workload data
                                       # or closed-form files are missing
python3 aggregate.py                   # -> results/summary*.csv, ../paper/generated/
python3 main_tables.py                 # main-text tables + \NumMain macros (reads summaries)
cd ../figures && for f in f*.py; do python3 "$f"; done   # f*.py and fm_*.py
python3 ../reference/figure_examples.py   # entries of the worked Figures 2 and 3
# paper, supplement and erratum (xr between paper and supplement): ../paper/build.sh
```

`verify.py` needs `workloads/data/` (for the closed-form `.expected.betti`
files); it refuses to run without them rather than report fewer checks.
`aggregate.py` and the figure scripts read only files under `results/`.

## Single rerun (review round)

`results/rerun/w2_N22_s8__mmhm-norb__seed1.*` is one rerun of the E1 run that
was a timing outlier (same command as in `results/E1/manifest.csv`). The
original stays in every table; the rerun's numbers are separate macros
(`\NumOutlierRerun…`).

## Outputs

| file | content |
|---|---|
| `results/<exp>/<workload>__<method>__seed<k>.csv.gz` | engine CSV (SPEC §7) or GUDHI CSV, one row per update |
| `results/<exp>/<workload>__<method>__seed<k>.betti.gz` | Betti file (SPEC §6.2) |
| `results/E0_correctness.csv` | per exact run: internal checks, comparisons with full-id / closed form / GUDHI, coverage counts |
| `results/E0_lcr.csv`, `results/E0/samples_crosscheck.csv` | v1-rule error rates; sample cross-check |
| `results/summary.csv` | per (experiment, instance, method), seeds pooled: percentiles, amortized, per-seed ranges, speedups (matched), 200-update block medians/means |
| `results/summary_runs.csv` | per run |
| `results/summary_slopes.csv`, `summary_e7.csv`, `summary_e8.csv`, `summary_w4_betti.csv`, `summary_rebuild_effect.csv`, `summary_drift.csv`, `summary_build.csv`, `summary_pairs.csv`, `summary_noise.csv`, `summary_coverage.csv` | see `aggregate.py` docstring |
| `results/noise/` | noise / interference raw runs |
| `results/WORKLOADS_MANIFEST.csv`, `results/ENGINE.txt` | provenance |
